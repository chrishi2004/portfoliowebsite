This is exactly how I would approach it if I were building a **premium personal brand website**. Don't think of it as "just a portfolio." Think of it as a **digital product** with a clear user journey.

The document below is written as a **Product Requirements Document (PRD)** that you can hand to an AI coding agent (Claude Code, Cursor, Windsurf, Lovable, Bolt, v0, etc.) to build the site.

# PRD: Premium Personal Portfolio Website

## Project Name

**Rishi Chaudhari | Portfolio**

---

# 1. Vision

Create a premium, minimal, Apple × Stripe × Linear inspired portfolio that positions me as a future Software Engineer, AI Engineer, Technology Consultant and Business Analyst.

The website should not look like a student portfolio.

It should feel like a modern SaaS product built by a company.

When recruiters visit, they should immediately feel:

* Professional
* Clean
* Premium
* Detail-oriented
* Technical
* Business focused

# Development Roadmap (For the AI Agent)

### Phase 1 — Foundation

* Initialize Next.js project with TypeScript.
* Configure Tailwind CSS, shadcn/ui, Framer Motion, and Lucide icons.
* Set up routing, fonts, theme provider (light/dark), SEO defaults, and responsive layout.

### Phase 2 — Design System

* Create reusable components: Navbar, Footer, Button, Card, Section, Timeline, Badge, Modal, Project Card, Achievement Card.
* Define spacing, colors, typography, shadows, borders, and animation tokens.

### Phase 3 — Home Page

* Build the Hero section with CTAs.
* Add subtle background gradients and micro-animations.
* Implement the About preview and statistics cards.

### Phase 4 — Core Sections

* Build About, Experience, Leadership, Skills, Achievements, and Certifications.
* Use timeline and card layouts.
* Ensure all sections are responsive.

### Phase 5 — Projects

* Create a reusable case-study template.
* Add project gallery, architecture diagrams, technology stack, screenshots, GitHub, and live demo links.
* Include filtering by category (AI, Analytics, Full Stack, Leadership).

### Phase 6 — Contact & Resume

* Add a contact form with validation.
* Embed the resume viewer and provide a download button.
* Add social links and location.

### Phase 7 — Polish

* Optimize images.
* Add loading states and page transitions.
* Complete SEO metadata, Open Graph tags, sitemap, robots.txt, and favicon.
* Verify Lighthouse scores and accessibility.

## Final Design Principle

One sentence should guide every design decision:

> **"If Apple were hiring an AI engineer with strong consulting and leadership experience, this is the portfolio they should expect to see."**

This keeps the website focused, timeless, and professional while showcasing both your technical depth and your ability to communicate business impact.
